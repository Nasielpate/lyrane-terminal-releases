# Lyrane Terminal – Downloads

Hier liegen nur die fertigen, von Apple notarisierten Versionen von Lyrane Terminal (früher „Wolf Terminal“) und die Update-Liste
(`appcast.xml`), über die sich installierte Programme selbst aktualisieren (Sparkle).

Herunterladen: unter **Releases** die neueste `.dmg` öffnen und Lyrane Terminal in „Programme“ ziehen.
